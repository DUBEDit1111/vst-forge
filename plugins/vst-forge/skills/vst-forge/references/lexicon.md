# Producer label lexicon

What producers already read without thinking. Sources: Ableton Live stock devices,
common hardware panels, and widely used plugins. `check_labels.py` reads the
backticked terms in the four data sections below, so keep one term per backtick
pair and keep the section headings unchanged.

- `chi` / `coherence` → Detect, Sensitivity
- `divergence` → Spread, Difference
- `collapse` → Narrow, Mono
- `dimension` / `hyper` → Width, Spread, Depth
- `flux` → Movement
- `fractal` → Spread, Time Spread
- `lattice` → Grid, Pattern
